# Astrangia_repo

This repository hosts data and analyses from [Ashey et al. 2026](https://doi.org/10.1242/jeb.253001), which examined mRNA-miRNA dynamics in the temperate coral *Astrangia poculata*. 

## Links

- [Manuscript](https://doi.org/10.1242/jeb.253001) published in JEB
- [![SRA](https://img.shields.io/badge/SRA-PRJNA1231118-blue)](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1231118/) - Raw RNA sequences stored on NCBI. 
- [![SRA](https://img.shields.io/badge/SRA-PRJNA1231129-blue)](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1231129/) - Raw small RNA sequences stored on NCBI.
